# API実装進捗管理

API 実装をユースケース単位で分担し、担当、進捗、関連ブランチ、関連 PR をリポジトリ上で追跡するためのドキュメントです。

## 運用ルール

- API 実装の着手時に、該当ユースケースの担当と作業ブランチを更新する。
- PR 作成時に、関連 PR 欄へ PR 番号または URL を追記する。
- API 仕様、Request / Response、認可条件に差分が出た場合は、関連する API 設計ドキュメントも同じ PR で更新する。
- 完了判断は、実装、テスト、API 設計ドキュメントとの差分確認が終わった状態とする。

## ステータス定義

| ステータス | 意味 |
| --- | --- |
| 未着手 | 担当または実装方針が未確定 |
| 実装中 | 実装作業中 |
| レビュー中 | PR 作成済み、レビュー待ちまたは修正中 |
| 完了 | merge 済み、または実装と確認が完了 |
| 保留 | 仕様確認や別作業待ち |
