# 認可ルール

このドキュメントでは、各操作を誰が実行できるかを整理する。

MVPでは、ログインユーザーとURL参加者をまとめて `event_members` として扱う。

---

| 操作 | 実行可能ユーザー |
| --- | --- |
| ユーザー登録 | 誰でも可能 |
| ログイン | 誰でも可能 |
| ログアウト | ログインユーザー |
| ログイン中ユーザー取得 | ログインユーザー |
| イベント作成 | ログインユーザー |
| イベント一覧取得 | ログインユーザー |
| イベント詳細取得 | イベント参加者 |
| イベント編集 | owner |
| イベント削除 | owner |
| 招待URL発行 | owner |
| 招待URL無効化 | owner |
| 招待URLからのイベント概要取得 | 誰でも可能 |
| URL参加 | 誰でも可能 |
| ローカルトークン再参加 | 有効なローカルトークンを持つユーザー |
| 参加者一覧取得 | イベント参加者 |
| 自分のイベント内メンバー情報取得 | イベント参加者 |
| 参加者表示名変更 | 本人またはowner |
| 参加者削除 / 退出 | 本人またはowner |
| 予定候補作成 | イベント参加者 |
| 予定候補編集 | 作成したevent_member本人、またはowner |
| 予定候補削除 | 作成したevent_member本人、またはowner |
| 予定確定 | owner |
| 予定取消 | owner |
| コメント一覧取得 | イベント参加者 |
| コメント投稿 | イベント参加者 |
| コメント削除 | 投稿したevent_member本人、またはowner |
| コメントいいね | イベント参加者 |
| コメントいいね解除 | イベント参加者 |
| Google Maps URL解析 | ログインユーザー、またはイベント参加者 |
| Google Places候補取得 | イベント参加者 |
| Google Place詳細取得 | イベント参加者 |

---

# 認可エラー

権限がない操作を行った場合は、403を返す。

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "この操作を行う権限がありません"
  }
}

---

# MVPでの方針

MVPでは、以下のようにシンプルに扱う。

| 項目 | 方針 |
| --- | --- |
| イベント閲覧 | ログイン済みユーザーなら可能 |
| イベント編集 | イベント作成者のみ可能 |
| イベント削除 | イベント作成者のみ可能 |
| 予定候補作成 | ログイン済みユーザーなら可能 |
| 予定候補編集 | 作成者またはイベント作成者のみ可能 |
| 予定候補削除 | 作成者またはイベント作成者のみ可能 |
| 予定確定 | イベント作成者のみ可能 |
| コメント投稿 | ログイン済みユーザーなら可能 |
| コメント削除 | コメント作成者のみ可能 |

---

# MVP後に検討する認可

MVP後に、参加者管理や招待リンクを導入する場合は、以下を検討する。

| 項目 | 検討内容 |
| --- | --- |
| イベント閲覧 | 招待されたユーザーのみ閲覧可能にする |
| コメント投稿 | イベント参加者のみ投稿可能にする |
| 予定候補作成 | イベント参加者のみ作成可能にする |
| 共有URL | URLを知っている人のみ閲覧可能にする |
| 参加者管理 | イベント作成者が参加者を追加・削除できるようにする |
